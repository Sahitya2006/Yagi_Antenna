# Yagi_Antenna
A Yagi-Uda antenna is a directional beam antenna built with a central boom supporting one active driven element and multiple passive parasitic elements (a reflector and directors) to achieve high gain and directivity.

# Antenna Specs - 
Operating Frequency - 865.5MHz
No. of elements - 03 {Reflector, Dipole and a director }

# WORKFLOW
### 1.Prototype
Steel tape Yagi anetnna is a popular designing style for prototyping before actual preparation. 
Made with steel tape of width- 16mm and thickness about 0.5mm. 

### 1.Calculations 
The model for calculations and mesaurements are performed using Mathwork antenna toolbox data, specifically mentioned for Yagi antenna. The Output screenshots can be seen and the matlab file is uploaded as well.(yagiSK.m file)

### 2.Simulations
The measurements once generated and verified from the matlab scripts were taken and used to design a exact antenna model in CST Suite Microwave and RF workspace. The file and resultant plots are available to check out.  
The Plots and radiation pattern images can be referred from my CST document.
